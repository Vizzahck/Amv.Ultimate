Autorização segura. O token não fica no código do site nem é salvo no navegador. Ele é usado apenas nesta aba para enviar suas alterações à API do GitHub.
Como criar o token autorizado?
  1. Entre no GitHub com sua conta com permissão de editar a AMV.
  2. Crie um Fine-grained personal access token com expiração curta.
  3. Permita acesso somente ao repositório Vizzahck/Amv.Ultimate.
  4. Em Repository permissions, permita Contents → Read and write.
  5. Cole o token acima apenas aqui; nunca o envie por mensagem.
